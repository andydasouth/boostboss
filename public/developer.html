Run this in your project directory — that's the whole install

npx @boostbossai/install-desktop pub_abc
One command. The CLI detects Electron or Tauri, patches your renderer HTML to add the Lumi script tag, and prints a banner showing all 10 placements that auto-enabled. Restart your app — the Computer App verify badge below flips to Connected within 60 seconds. To uninstall: npx @boostbossai/install-desktop --uninstall
🪟 Electron
CLI patches your renderer's index.html. No code edits needed.
🦀 Tauri
Manual integration in v1.2. See /docs/computer#tauri.
🎥 Sound + video
Desktop apps escape browser autoplay rules. Pre-roll video with sound is fully supported.

Paste this in your <head> — that's the whole install

<script async src="https://boostboss.ai/lumi/v1.js#pub_abc"></script>
One paste. Refresh your site — the Browser App verify badge below flips to Connected within 30 seconds. All 8 placements auto-enable. No npm install, no init(), no slot tags.
🔒 Privacy posture
Lumi reads only what's visible on the active tab. Nothing is persisted to cookies, localStorage, or IndexedDB. Page URL + impression context is all that leaves the page.
🛡 Strict CSP?
Add boostboss.ai to your script-src and connect-src directives. One line each. Reference →
⚛ React / Next.js?
12-line wrapper for component-style integration. /docs/browser/react →

Run this in your extension directory — that's the whole install

npx @boostbossai/install-extension pub_abc
One command. The CLI installs the runtime, patches your manifest.json (permissions + host), drops the SDK into your service worker, and wires popup + sidepanel + new-tab pages if they exist. Reload your extension in chrome://extensions — the Browser Extension verify badge below flips to Connected within 60 seconds. Uninstall: npx @boostbossai/install-extension --uninstall
🧩 Manifest V3
Chrome / Edge / Brave / Opera. Zero eval, zero remote code. Bundled into node_modules at install.
⚡ Premium placement
New-tab takeover at $16 RPM — auto-enables when your manifest declares a new-tab override.
🔧 Firefox / Safari
v1.2 supports Chrome MV3 only. Firefox / Safari ports follow in v1.3. Track progress →

Mobile App — pick your stack

React Native covers most AI mobile apps. If your app is native iOS (Swift / Obj-C) or native Android (Kotlin / Java), use those tabs instead — the underlying SDK is the same, just packaged for each ecosystem's native package manager. 
npx @boostbossai/install-mobile pub_abc
One command. The CLI detects Expo vs bare React Native, installs the runtime, wraps your App.tsx root with <LumiProvider>, and runs pod install on Mac. Rebuild — the Mobile App verify badge flips to Connected within 60 seconds. Uninstall: npx @boostbossai/install-mobile --uninstall
🏆 Rewarded video
Highest-CPM format in adtech ($25–50 CPM). User opts in, you grant them a reward. Drop in: <RewardedVideo onReward={fn} />
📱 Expo + Bare RN
CLI auto-detects and patches the right entry point. Expo SDK 50+ or React Native 0.74+.
🎵 Sound + video
Native apps escape browser autoplay rules. Pre-roll, rewarded, full-screen — all sound-on, App Store / Play Store compliant.
v0.1.1-alpha · all 10 placements ship in the SDK. 2 auto-mount on launch (BottomBanner, SplashSponsor). 5 are embedded by you in your layout (InlineNativeBanner, InlineSponsoredCard, SponsoredCitation, SuggestedChip, LoadingStateAd). 3 are event-driven by you per Apple App Store rules (RewardedVideo, Interstitial, PreRollVideo). SKAdNetwork install attribution ships in v0.2.
